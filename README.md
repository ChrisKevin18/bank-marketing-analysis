# 📊 Bank Marketing Data Analysis

## 📌 Project Overview
This project analyzes the Bank Marketing dataset to understand customer behavior and predict whether a client will subscribe to a term deposit.

The dataset contains demographic, financial, and campaign-related information collected during direct marketing campaigns of a Portuguese banking institution.

---

## 🎯 Objectives
- Perform Exploratory Data Analysis (EDA)
- Identify data imbalance in subscription variable
- Analyze correlations among numerical features
- Prepare dataset for future machine learning modeling

## 📊 Key Insights
- Majority of customers do not subscribe to term deposits.
- Limited strong correlations between numerical features.
- Dataset requires preprocessing before modeling.
